## Быстрый старт

1. **Возьмите подписанный APK после публикации.** Целевой выпуск — `0.5.0` (`versionCode` 9). Используйте [будущую страницу v0.5.0](https://github.com/papajon123/meshcentral-android/releases/tag/v0.5.0) или личный репозиторий F-Droid после объявления ведущего. Нужен Android 8.0 (API 26) или новее.
2. **Установите приложение.** Android попросит разрешить установку из браузера или файлового менеджера. Для обновления нужны то же имя пакета, тот же ключ подписи и больший `versionCode`.
3. **Подключите свой сервер.** Введите полный HTTPS-адрес своего MeshCentral, например `https://meshcentral.example.com/`, и войдите. Предустановленного сервера и учётной записи нет.

## Что даёт 0.5.0

- **Сведения о компьютере и вкладки.** Откройте компьютер из списка, чтобы увидеть группу, ОС, адрес и версию агента, затем выберите «Сведения», «Рабочий стол», «Терминал», «Файлы», SSH или SFTP.
- **Рабочий стол Mesh Agent.** Нативное KVM-управление с касаниями, тачпадом, клавиатурой, текстовым буфером, переключением мониторов и переподключением.
- **Терминал Mesh Agent.** Настоящая командная оболочка на управляемом компьютере; вывод рисует локально встроенный xterm.js, транспортом управляет Kotlin.
- **Файлы Mesh Agent.** Просмотр каталогов, скачивание в выбранный документ, загрузка, создание папки, переименование и удаление.
- **SSH и SFTP через MeshCentral.** Используются SSH-точки сервера и серверная проверка подлинности SSH; Android не открывает прямое SSH-соединение.
- **Вкладки по возможностям.** Известный запрет или неподдерживаемая функция отключают вкладку; при отсутствии метаданных разрешена явная попытка, окончательное решение остаётся за сервером.
- **Один инструмент за раз.** Выбор другой вкладки терминала/файлов или рабочего стола закрывает предыдущий инструмент. При реальной потере канала управления, сервера или учётной записи инструмент закрывается; обычное пересоздание Activity сохраняет ViewModel и живой сеанс. Терминал и файлы не переподключаются и не повторяют ввод или файловые изменения автоматически.
- **22 языка.** По 529 переведённых строк в каждом из 23 вариантов локали; язык следует системному.

Вне нативного клиента 0.5.0 остаются Intel AMT KVM, RDP, VNC и WebRTC, события устройства, пробуждение и питание, чат, управление реестром и программами, администрирование сервера. Для этого есть **Open web panel**: сервер открывается в браузере с отдельным входом.

## Экран компьютера

Вкладка «Сведения» доступна всегда. Остальные включаются, только когда текущая учётная запись, компьютер и сервер могут их поддерживать. Состояния разделены намеренно:

- **известный запрет** — у учётной записи нет нужного права, компьютер офлайн или сервер сообщил об отключённой функции;
- **неизвестно** — сервер не прислал необязательные метаданные; вкладку можно попробовать открыть явно, и ответит сервер.

Приложение не выводит разрешение из отсутствующего поля. Для SSH/SFTP также нужны соответствующие флаги сервера; терминал и файлы агента используют биты возможностей агента, если сервер их прислал.

| Вкладка | Транспорт | Примечание |
|---|---|---|
| Сведения | данные канала управления | Группа, ОС, адрес, версия агента; событий и управления питанием нет. |
| Рабочий стол | `/meshrelay.ashx?p=2` | Прежний нативный KVM-путь Mesh Agent. |
| Терминал | `/meshrelay.ashx?p=1` | Оболочка Mesh Agent через сервер MeshCentral. |
| Файлы | `/meshrelay.ashx?p=5` | Файловый протокол агента, отдельно от SFTP. |
| SSH | `/sshterminalrelay.ashx` | SSH выполняет MeshCentral, не Android. |
| SFTP | `/sshfilesrelay.ashx` | SFTP на стороне сервера в рамках авторизованной сессии MeshCentral. |

## Терминал

Терминал — **локальный рендерер**: `@xterm/xterm` 5.5.0 и `@xterm/addon-fit` 0.10.0 встроены в APK в `app/src/main/assets/terminal/` (MIT; см. [сторонние уведомления](THIRD_PARTY_NOTICES.md)). Ввод, изменение размера и сигналы готовности/приёма идут через узкий локальный DOM-мост; вывод записывается в локальный рендерер. Ретранслятором, авторизацией и жизненным циклом владеет Kotlin. JavaScript не получает адрес сервера, cookie, имя пользователя, пароль, закрытый ключ или путь в файловой системе.

Локальное представление не имеет доступа к сети и файлам и отклоняет удалённую навигацию. Гиперссылки OSC 8 и запись в буфер OSC 52 отключены. Копирование — только явное действие на панели и только для выделения терминала. Нужен рабочий обновлённый **Android System WebView**; если он не запускается, приложение показывает понятную инструкцию обновить/открыть заново, а не пустой экран.

Терминал отправляет обычные клавиши, а также Ctrl, Esc, Tab, стрелки и Enter. Очереди вывода ограничены: чтение ждёт освобождения места, слишком большой отдельный кадр отклоняется явно, молчаливого отбрасывания нет. Сеанс инструмента **не** переподключается сам и никогда не повторяет прежний ввод; для новой попытки откройте вкладку заново.

MeshCentral может записывать терминальный сеанс. Если ретранслятор Mesh Agent сообщает об этом, приложение показывает уведомление. Проверенная реализация ретранслятора SSH не передаёт этот признак клиенту; отсутствие уведомления не доказывает, что записи на сервере нет.

## Файлы

Вкладки «Файлы» агента и SFTP используют разные протоколы, но предлагают одинаковые основные действия:

- просмотр каталогов и обновление;
- скачивание в документ, выбранный через Storage Access Framework (SAF);
- загрузка файла с предупреждением о перезаписи;
- создание папки, переименование и удаление с явным подтверждением.

Загрузки и через агента, и через SFTP проверяются после подтверждения сервера: приложение читает загруженное содержимое обратно через ретранслятор, сравнивает SHA-256 с исходником и проверяет имя и стабильный размер в свежем листинге. Успех не объявляется по одному подтверждению.

Перед скачиванием приложение берёт точный размер из свежего листинга, открывает документ SAF с усечением и проверяет результат после передачи. Адаптер SFTP корректно обрабатывает пустой файл и файл, размер которого кратен размеру блока, не ожидая EOF, которого сервер не присылает. Неудачное или отменённое скачивание всё равно может оставить частичный документ в выбранном пользователем месте; приложение сообщает о частичном результате и не удаляет и не перезаписывает этот документ.

Ответ каталога ограничен 1 МиБ JSON и 20 000 записей; превышение отклоняется, а не обрезается молча. Имена, которые нельзя безопасно создать или обработать, показываются только для чтения, с переходом в веб-панель. Автоматических повторов, докачки и повторного выполнения файловых изменений нет.

Отмена ещё не подтверждённых mkdir, rename или delete помечается как непроверенная, а не как успешная: сервер мог уже применить изменение. Живая семантика отмены таких изменений остаётся пунктом проверки.

## SSH и SFTP через MeshCentral

SSH завершается на сервере MeshCentral и доступен через `/sshterminalrelay.ashx`; SFTP использует `/sshfilesrelay.ashx`. Android не подключается к SSH-хосту напрямую. Эти сокеты просмотра используют **ту же выданную сервером cookie авторизации**, что и нативный канал управления/ретрансляции; пароль или ключ SSH передаётся только в текущей авторизованной сессии.

- Пароли SSH, закрытые ключи и парольные фразы хранятся в памяти только для запроса и исходящего сообщения. Новые учётные данные отправляются с `keep=false` (SFTP) или `keep:0` на пути терминала агента, где флаг числовой; приложение их не сохраняет.
- Ключ, сохранённый на сервере, можно разблокировать парольной фразой через сообщение `sshkeyauth`; сам ключ и парольную фразу приложение всё равно не хранит.
- **Приложение не заявляет проверку host key на Android.** Прямого SSH-стека и хранилища host key у него нет. Политика host key относится к серверу и не проверялась живьём для этого выпуска.
- Сервер SSH/SFTP может записывать сеанс. Приложение не может гарантировать отсутствие записи на стороне сервера.

## Безопасность и приватность

- Без рекламы, аналитики, телеметрии, службы отчётов о сбоях, учётной записи проекта и собственного сервера. Нативный клиент обращается только к указанному серверу MeshCentral: `/control.ashx`, `/meshrelay.ashx` (рабочий стол, терминал и файлы агента), `/sshterminalrelay.ashx` и `/sshfilesrelay.ashx`.
- Рендерер терминала — **локальный** WebView с ресурсами из APK и заблокированными сетью и файлами. Это не то же самое, что сырой **Debug WebView** в настройках: тот загружает страницу настроенного MeshCentral и хранит собственные cookie WebView.
- Учётные данные MeshCentral и PIN приложения шифруются ключом AES-GCM в Android Keystore. Резервное копирование и перенос отключены. Cookie сеанса остаются в памяти процесса; очистить данные можно в **Настройки → Данные**.
- Кадры рабочего стола, вывод терминала, текст буфера и содержимое передаваемых файлов проходят через MeshCentral и управляемый компьютер. Приложение не записывает экран и не сохраняет вывод терминала в локальное хранилище; копия выделения терминала попадает в буфер Android только по явному действию.
- Блокировка приложения — PIN, биометрия Android (9+) или оба способа. Блокировка скриншотов через `FLAG_SECURE` выключена по умолчанию и не защищает от камеры.
- Оператор сервера видит метаданные подключения, активность устройств и сеансов и трафик через сервер. Журналирование, запись терминала и управление доступом — вне приложения.

См. [Приватность](PRIVACY.md) и [Политику безопасности](SECURITY.md).

## Языки и состояние переводов

- Переводы выполнены с помощью DeepSeek и **не** вычитаны носителями всех языков.

## Сборка из исходного кода

Требования: JDK 17, Android SDK platform 35, build-tools 35.0.0. Gradle wrapper скачивает Gradle 8.10.2.

Windows PowerShell (`JAVA_HOME` и `ANDROID_HOME` должны указывать на ваши установки; замените заглушку JDK на свой путь к JDK 17):

```powershell
$env:JAVA_HOME = "C:\path\to\jdk-17"
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
.\gradlew.bat assembleDebug
```

Linux или macOS:

```bash
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME="$HOME/Android/Sdk"
./gradlew assembleDebug
```

Отладочный APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Тесты и проверка переводов

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
python3 ci/check_translations.py
python3 -m unittest discover -s ci -p 'test_*.py'
```

В Windows для задач Gradle используйте `.\gradlew.bat`. Инструментальные тесты требуют отдельного эмулятора или тестового устройства без личных данных; применяйте зарезервированные домены и синтетические данные:

```bash
./gradlew connectedDebugAndroidTest
```

`ci/check_translations.py` сверяет 23 варианта с базовым каталогом, проверяет подстановки формата, отсутствие русского текста в других локалях и текущие **529 переведённых строк** в каждом варианте. Полные результаты JVM-тестов, проверок на устройстве и стенде, а также условия выпуска — в [Проверке](docs/VALIDATION.md); здесь число тестов намеренно не приводится.

## Сообщить об ошибке

Откройте [задачу на GitHub](https://github.com/papajon123/meshcentral-android/issues) и укажите версию приложения, Android, MeshCentral, шаги воспроизведения и очищенные журналы. **Не** публикуйте учётные данные, cookie сеанса, закрытые ключи, реальные имена серверов, вывод терминала с секретами и снимки работающего рабочего стола. Проблемы безопасности направляйте через закрытый канал в [SECURITY.md](SECURITY.md).

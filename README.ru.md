# MeshCentral Mobile — русская инструкция

Независимый нативный Android-клиент для существующего сервера [MeshCentral](https://github.com/Ylianst/MeshCentral). Он позволяет войти на свой сервер, увидеть компьютеры и открыть удалённый рабочий стол Mesh Agent с телефона или планшета.

Приложение разрабатывается независимо от команды MeshCentral. Это клиент управления компьютерами; для работы нужны собственный сервер MeshCentral и учётная запись на нём.

> **Статус: 0.4.0 (versionCode 8), предварительный выпуск.** Сборка ещё не проверялась на физическом устройстве и на сторонних серверах. Интерфейс переведён на 22 языка (23 варианта), язык по умолчанию — английский; переводы ещё не вычитаны носителями всех языков. См. [известные ограничения](docs/KNOWN_LIMITATIONS.md).

## Скачать и установить

- APK: [GitHub Releases](https://github.com/papajon123/meshcentral-android/releases).
- Android 8.0 (API 26) или новее.
- Откройте скачанный APK. Android попросит разрешить установку из приложения, через которое вы открыли файл: разрешите установку из этого источника для браузера или файлового менеджера и подтвердите установку.
- Обновления устанавливаются вручную: скачайте новый APK из Releases. Android примет обновление, только если совпадают имя пакета (`io.github.papajon123.meshcentral`) и ключ подписи, а `versionCode` больше. Сборка, подписанная вашим ключом, не установится поверх APK из Releases.

Версия 0.4.0 сохраняет имя пакета и ключ подписи публичного 0.3.0, поэтому устанавливается поверх него и сохраняет данные входа — повторный вход не обязателен. Более ранние частные сборки остаются отдельными приложениями и требуют своего входа. У отладочных сборок к имени пакета добавляется суффикс `.debug`.

Публичный отпечаток сертификата подписи SHA-256:

`5458084705359e0dfa9cbb83ed73a0d77c7758370cffe2a7d6b036e9275eeb2f`

Это открытый отпечаток, а не закрытый ключ и не секрет. В каждом выпуске есть контрольные суммы APK и `release-info.json`; порядок выпуска описан в [docs/RELEASING.md](docs/RELEASING.md).

## Языки интерфейса

Интерфейс 0.4.0 переведён на 22 языка (23 варианта); язык по умолчанию — английский:

English, русский, 简体中文, 繁體中文, español, français, português, Deutsch, العربية, हिन्दी, বাংলা, اردو, 日本語, 한국어, Bahasa Indonesia, Türkçe, Tiếng Việt, ไทย, italiano, فارسی, தமிழ், తెలుగు, मराठी.

Упрощённый и традиционный китайский считаются одним языком и двумя вариантами локали. В каждом варианте переведены одни и те же 389 строк; название приложения общее.

- Android 8–12: приложение автоматически следует языку системы.
- Android 13 и новее: язык приложения также выбирается в штатных настройках Android (обычно **Настройки → Система → Языки и ввод → Языки приложений** либо на странице приложения; точный путь зависит от производителя). Отдельного выбора языка внутри приложения нет.
- Если ни один из поддерживаемых языков не подходит, используется английский.
- Для арабского, персидского и урду интерфейс строится справа налево; стрелка навигации зеркалится.
- Сообщения сервера, имена устройств и подписи физических клавиш (`Ctrl`, `F1`, …) не переводятся.
- Переводы выполнены с помощью DeepSeek и ещё не вычитаны носителями всех языков. Онлайн-перевод и геолокация не используются.

## Свой сервер

  <img src="docs/screenshots/setup.png" width="260" alt="Первый запуск с пустым адресом сервера">
  <img src="docs/screenshots/sign-in.png" width="260" alt="Экран входа с зарезервированным примером сервера">
</p>

- Введите полный URL MeshCentral вручную, например `https://meshcentral.example.com/`. Предустановленного сервера нет.
- Используйте HTTPS с сертификатом, действительным для этого имени хоста. Публикуемая сборка проверяет сертификаты по системному хранилищу доверия Android.
- Указывайте окончательный URL сервера. Аутентифицированные запросы не следуют HTTP-перенаправлениям. Пути домена сохраняются в URL управления и просмотра; для живых развёртываний с подпутями обратного прокси совместимость ещё нужно проверять.
- HTTP без TLS и самоподписанные сертификаты доступны только в отладочных сборках для локального тестового сервера.
- Учётной записи нужно право удалённого управления для группы компьютеров; сеансы только для просмотра поддерживаются.

## Возможности

- Нативный рабочий стол Mesh Agent через ретранслятор MeshCentral: переключение мониторов, переподключение и готовые настройки качества.
- Режимы указателя «касание» и «тачпад», масштабирование щипком до 16×, ограниченное панорамирование и указатель, который рисует клиент.
- Экранная клавиатура, сетка сочетаний клавиш, ввод Unicode и сеансы только для просмотра, которые не отправляют ввод.
- Обмен текстовым буфером обмена в обе стороны в пределах ограничений MeshCentral и Mesh Agent.
- Двухфакторный вход по электронной почте, SMS или уведомлению, если сервер это предлагает.
- Учётные данные и PIN защищены Android Keystore AES-GCM; дополнительная блокировка приложения по PIN или биометрии и дополнительная блокировка скриншотов.
- Сохранённые учётные данные и незавершённые поля входа изолируются при смене адреса сервера.
- Интерфейс на 22 языках (23 варианта), по умолчанию английский: автоматический выбор языка системы, штатная настройка языка приложения на Android 13+ и раскладка справа налево для арабского, персидского и урду.
- Без рекламы, аналитики, телеметрии и сервера автора. В выпуске 0.4.0 нет встроенного магазина, самообновления и установки APK из приложения.

## Ограничения

- Поддерживается только нативный путь рабочего стола Mesh Agent: `/meshrelay.ashx?p=2` через сервер MeshCentral.
- Не реализованы Intel AMT KVM, Web-RDP, Web-VNC, WebRTC, терминальные сеансы, управление файлами, устройства без агента, браузерный SSO и изображения в буфере обмена.
- Клиент написан под MeshCentral 1.2.5; совместимость с другими версиями сервера не заявлена.
- Вход использует заголовок `x-meshauth`, а не браузерную форму. Ключи доступа в URL домена (`?key=`) не поддерживаются.
- Приложение не администрирует сервер: не создаёт группы компьютеров, пользователей, политики и настройки сервера.
- Обратный прокси, который блокирует обновление до WebSocket, нарушит вход или сеанс рабочего стола. Приложение не настраивает Nginx, сертификаты, межсетевые экраны и сам MeshCentral.
- Резервный WebView для диагностики доступен только в отладочной сборке. Английская документация проекта не означает, что интерфейс доступен только на английском: язык выбирается системой.

## Приватность

- У приложения нет проектной учётной записи, рекламы, аналитики, телеметрии и SDK отчётов о сбоях. Оно подключается только к указанному вами серверу MeshCentral: `/control.ashx` для входа и управления, `/meshrelay.ashx` для ретрансляции рабочего стола.
- Учётные данные MeshCentral и PIN приложения шифруются ключом Android Keystore. Резервное копирование Android и перенос на новое устройство отключены.
- Сеансовые cookie хранятся в памяти процесса и очищаются при выходе или завершении процесса. Cookie WebView используются только при включённом резервном режиме и очищаются действием в **Настройки → Данные**.
- Кадры экрана декодируются в память; приложение не записывает экран и не сохраняет кадры. Ввод и текст буфера передаются на управляемый компьютер через ваш сервер. Буфер обмена работает только по явному действию пользователя.
- Блокировка скриншотов (`FLAG_SECURE`) необязательна и по умолчанию выключена. Биометрическая разблокировка использует `BiometricPrompt`, требует Android 9 или новее, а PIN остаётся запасным способом.
- Оператор сервера видит IP-адрес, имя учётной записи, список устройств, время сеансов и трафик удалённого управления. Политики журналирования и доступа задаёт владелец сервера.
- Сохранённые учётные данные и текущий сеанс можно удалить в **Настройки → Данные**. Удаление приложения стирает локальные данные, но ничего не удаляет с сервера MeshCentral.
- Подробности: [PRIVACY.md](PRIVACY.md).

## Сборка

Требования: JDK 17, Android SDK platform 35, build-tools 35.0.0. Сценарий gradlew скачивает Gradle 8.10.2.

Windows PowerShell (`JAVA_HOME` и `ANDROID_HOME` должны указывать на ваши установки; замените заглушку JDK на свой путь к JDK 17):

```powershell
$env:JAVA_HOME = "C:\path\to\jdk-17"
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
.\gradlew.bat assembleDebug
```

Linux или macOS:

```bash
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME="$HOME/Android/Sdk"
./gradlew assembleDebug
```

Отладочный APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Тесты

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

В Windows используйте `.\gradlew.bat` с теми же задачами.

Инструментальные тесты требуют отдельного эмулятора или тестового устройства; применяйте зарезервированные примеры доменов и синтетические данные устройств:

```bash
./gradlew connectedDebugAndroidTest
```

Каталоги переводов проверяются отдельно:

```bash
python3 ci/check_translations.py
python3 -m unittest discover -s ci -p 'test_*.py'
```

`ci/check_translations.py` проверяет, что во всех локалях одинаковые 389 строк, совпадают подстановки формата и русский текст не попадает в другие языки. Команда unittest запускает тесты самой проверки.

Итоговые числа тестов и свидетельства выпуска ведёт сопровождающий в [docs/VALIDATION.md](docs/VALIDATION.md).
